# Xingular Harness 1.1.1

The first published release of the 1.1 line, and npm `latest`. It follows the published 1.0.0
baseline. The 1.1.0 tag was pushed, but its release run stopped before publishing, so nothing was
published under 1.1.0.

## Agent profiles and named subagents

- A subagent can start from a named profile: the built-in `worker` and `explorer`, a person's
  `<data root>/agents/<name>.md`, a repository's `.xingular/agents/<name>.md`, or a variant's c5
  subagent. A profile narrows the child's tools and plugins and may choose its variant, model and
  effort (PROP-0029, ADR-0030).
- The parent names each subagent. `spawn_subagent` requires a short `title`; `subagents.spawn`
  takes an optional one (PROP-0030). The live roster, `/subagents` and the transcript show the
  title.
- The terminal runs the checklist tool and shows each write as a checklist block. An in-progress
  item shows a yellow dot, and a running subagent's row shows the working spinner in its profile's
  colour.

## Release pipeline

- The release pack and smoke scripts take their npm cache from the system temp folder. They
  previously used a macOS-only path, which failed on Linux runners.
- The `/help` terminal check matches the documented grouped, scrollable help: it pages until every
  group is seen, and its expected group is `Plugins`.

Checks for this release: `npm run ci` (148 test files, 1111 tests), the exact-tarball fresh
installation smoke test including the packaged terminal, and the release preflight.
