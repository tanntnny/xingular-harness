# Xingular Harness 1.4.0-unstable

Unstable preview of the current Harness work. Install with `npm install @xingular/harness@unstable`.

- **Long-running `/goal` sessions.** Start a bounded goal run, inspect and update its goal, pause or
  resume it, and let the completion check judge the goal when the run claims completion. Ordinary
  replies no longer incur a model-judged completion check.
- **Completion and continuation guidance.** Codex-inspired prompt sections cover autonomy,
  persistence, steering, compaction and clear handoffs. Reporting guidance is expanded with examples
  and concrete requirements for changes, checks, blockers and follow-up actions.
- **Skill installation and discovery.** The plugin-authoring skill documents supported skill
  locations and safe install routes. Foreign plugin manifests can expose skills, and plugin
  installation rejects repository `tree` and `blob` page URLs with actionable guidance.
- **Terminal and session fixes.** Terminal behavior now accounts for the goal lifecycle, retains the
  right completion behavior, and includes related prompt, status and lifecycle updates.

Test suites were not run for this candidate, at the request to bypass tests. The release workflow
still requires CI and exact-tarball smoke checks before publication.
