# Xingular Harness 1.3.1-unstable.1

Unstable preview of the current Harness work. Install with `npm install @xingular/harness@unstable`.

- Import agent profiles from compatible plugins and continue stopped subagents across interruptions and restarts.
- Improve Windows shell, workspace write and edit support, with explicit per-call approval where an OS write-boundary sandbox is unavailable.
- Extend Doctor to check the active shell and exercise its workspace boundary with a fixed, no-network probe.
- Improve terminal subagent progress and plugin management, plus work-slice and plan-research behavior.
