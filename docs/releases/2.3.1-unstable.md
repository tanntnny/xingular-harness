# Xingular Harness 2.3.1-unstable

Unstable preview building on 2.3.0-unstable. Install with `npm install @xingular/harness@unstable`.

- **Live compaction status appears in the terminal transcript.** An animated divider shows while context compacts, changes to the retry label when needed, and disappears when compaction ends. The working-status line remains visible. The parity register records the terminal and App surfaces.

Automated tests, CI test jobs and release smoke checks were skipped at the user's request. The package build, candidate integrity checks and published provenance verification ran; behavior is otherwise unverified by test suites.
