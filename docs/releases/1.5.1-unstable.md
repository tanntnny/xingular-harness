# Xingular Harness 1.5.1-unstable

Unstable preview of the current Harness work. Install with `npm install @xingular/harness@unstable`.

- **Tool names in the terminal transcript.** Tools render in CamelCase (`todo_write` becomes
  `TodoWrite`, `computer_screenshot` becomes `ComputerScreenshot`) instead of the raw tool id.
- **Claude Code prompt study.** `STUDY-0007` reads Claude Code v2.1.88's shipped prompt from the
  leaked source map and compares it with this harness's pack in 20 areas;
  `scripts/study-claude-prompt.mjs` reproduces the measurement.

Test suites were not run for this candidate, at the request to bypass tests.
