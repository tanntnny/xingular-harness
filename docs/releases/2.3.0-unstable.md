# Xingular Harness 2.3.0-unstable

Unstable preview of the current Harness work. Install with `npm install @xingular/harness@unstable`.
This release builds on 2.2.0-unstable with the following changes:

- **Terminal usage and Markdown.** Session token totals now include earlier runs and compacted messages. Wrapped lists use hanging indents for bullets, numbering and nested items.
- **Optional REA connector.** A disabled-by-default REA plugin ships its skill and optional pinned runtime. Its connection appears in `/connections` and `/mcp`; calls use the broker, approval gate and configurable deadlines.
- **Account model selection.** Normal and plan modes share the account's model and effort choice. Selections persist across conversations and resumed sessions.
- **Marketplace and plugin management.** `/marketplace` is canonical and `/hub` remains an alias. Plugin, skill and MCP-server terminology is clearer; installed packages stay manageable when they cannot be rediscovered. The built-in `tui-inspection` skill is on demand.
- **Reporting prompt guidance.** Final-answer guidance now permits content-named headings and concise edit labels while keeping titles and prose flexible.

All automated tests and CI checks were skipped at the user's request. The release is therefore unverified by test suites; this is an intentional release risk.
