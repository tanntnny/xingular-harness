# Xingular Harness 1.3.1-unstable.2

Unstable preview of the current Harness work. Install with `npm install @xingular/harness@unstable`.

- Swap the OpenTUI send keys back. `Return` sends, or steers a running reply, and `Cmd+Return`,
  `Ctrl+Return` or `Alt+Return` queues a follow-up. The `app.message.followUp` action replaces
  `app.message.steer`, so a `keybindings.json` entry under that name needs renaming.
- Show pending steering, follow-up and deferred plan/Bash inputs above the working line, each with
  its delivery type. A queued plan or `!` command is a barrier: it runs as a standalone turn and
  later inputs wait behind it instead of entering Pi's native queues.
- Restore queued text to the draft with `Alt+Up`. Queued images are dropped; deferred images warn.
