# Xingular Harness 1.3.1-unstable.3

Unstable preview of the current Harness work. Install with `npm install @xingular/harness@unstable`.

- Name a skill anywhere in a message: `$name` at any word start makes that skill required for the
  request (ADR-0048). `Launch.requiredSkills` carries it, and the compiler renders a
  `required-skills` section at order 52 from the pinned variant through `readSkillFile`, bounded at
  12,000 characters. An unavailable skill is named honestly instead of invented, and the built-in
  `plugin-authoring` skill stands in when the variant ships no skills. The section belongs to the
  request, so an identical one is delivered again rather than deduplicated. The terminal builds the
  same text with `requiredSkillsText` and appends it as a hidden `xingular-required-skills` message,
  so the person's own wording reaches the model unchanged. In the composer the `$` palette opens at
  the caret and inserts there, keeping the rest of the draft.
- Bound delegation per run and per profile (ADR-0052). A run now starts at most four distinct child
  conversations: two `worker`, three `explorer`, one of any other named profile and one with no
  profile. `SessionRunInput.subagents` / the SDK's `Subagents` options override them with
  `maxChildren`, `maxByProfile`, `maxOther` and `maxUnprofiled` (clamped to 0–50), and the model's
  `spawn_subagent` description states the budget it has left. `Subagents.spawn` refuses a child past
  a limit with `invalid_request` and starts no run; continuing a stopped child costs no slot, and a
  work-slice continuation keeps the parent's budget.
- Read what a request was made of. `context.attribution` returns one row per contributor with its
  estimated tokens and share of the window, reconciled to the provider's measured total, and one
  row's text on request; the terminal reaches it through `terminal.context`. The compiler now
  records where its characters went: `renderSized` returns each section's size and the framing that
  belongs to no section, `Delivery.sizes` stores them on the recorded pack, and `Source.chars`
  attributes a variant's tool guidance inside the tools section. `context.snapshot` also records the
  compaction headroom the run was held to (`compaction: { enabled, reserveTokens }`) from Pi's own
  settings. The terminal page over this data arrives in a later preview; no `/context` command is
  registered yet.
- Add an opt-in approved-window screenshot contract (ADR-0050). `src/computer/screenshot.ts` defines
  `computer_screenshot` for a host-supplied backend: it captures exactly one currently approved
  window, excludes the desktop, other windows and overlapping overlays, and refuses with
  `COMPUTER_SCREENSHOT_UNAVAILABLE` rather than returning display pixels. It goes through the
  ordinary tool gate, is not plan-mode safe, and adds no extension point. The standalone terminal
  has no backend, and the existing macOS host capture has not adopted this contract.
- Deliver approvals and questions promptly without polling: the control-key-protected
  `terminal.pending.wait` returns as soon as the pending revision changes and otherwise waits at most
  20 s, waking on additions, removals and disposal (ADR-0051). `terminal.pending` is unchanged and
  the server protocol is untouched.
- Swap the OpenTUI send keys back. `Return` sends, or queues a follow-up behind a running reply, and
  `Cmd+Return`, `Ctrl+Return` or `Alt+Return` steers that reply. The `app.message.followUp` action is
  `app.message.steer` again, so a `keybindings.json` entry under the newer name needs renaming.
- Keep a stray mouse report out of input. A report split across the input parser's timeout no longer
  types its `<button;column;row>` tail into the composer or a single-line field, so a scroll cannot
  become a run's prompt or a filter; typing and pastes are untouched and `/trajectory` no longer
  prints a recorded report.

## Upgrading

- A leading `$name` is no longer rewritten to Pi's `/skill:name`. An embedding host sends required
  skills as `Launch.requiredSkills`, and the message text reaches the model as written.
- Runs that spawned children freely now stop at the defaults above; set `subagents` explicitly to
  change them.
- A `keybindings.json` entry named `app.message.followUp` is now `app.message.steer`.
