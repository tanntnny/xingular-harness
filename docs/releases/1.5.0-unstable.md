# Xingular Harness 1.5.0-unstable

Unstable preview of the current Harness work. Install with `npm install @xingular/harness@unstable`.

- **No todo gate.** The stop gate, its three reminders and the `unfinished` status that open todo
  items produced are removed. A reply the model ends settles `completed`; the goal loop and the
  work-slice guard keep their stop codes and checkpoints. `XINGULAR_STOP_GATE` is retired.
- **Codex's final-answer guidance.** The reporting section adopts Codex's `gpt-6.1-sol` wording:
  self-contained final, outcome first, what changed and why, how it was tested, risks and limits,
  evidence summarized, tables for comparisons, length by complexity, prose before lists. It falls
  from 9.2k to 3.7k characters.
- **Personality and model identity.** A person's own session reads Codex's personality paragraph,
  and the identity names the model the session runs when the host knows it. The unclear-scope rule
  uses Codex's wording with `ask_user` for the follow-up.
- **Work rules and credentials.** The tool guidance gains Codex's `rg`-first search, shell quoting,
  command-separator, variable-name and test-restraint rules, plus the skill and plugin principles.
  A login that blocks the work is answered with the exact command.

Test suites were not run for this candidate, at the request to bypass tests.
